# Historical notebooks — audit only

These are the original, uncorrected notebooks and saved outputs. Their performance estimates are invalid for confirmatory use for the reasons in [the research audit](../../docs/research-redesign.md). They depend on absent inputs and contain known leakage. Do not use them as an execution entry point. The root notebooks and `sentiment_forecast` package replace their workflows.

Audit cell references in the original design document refer to these archived copies.
